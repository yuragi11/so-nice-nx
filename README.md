# SO NICE NX

Full-stack project structure for the SO NICE NX showroom prototype.

## Current implementation

The `backend/` folder contains the complete backend assignment implementation.

The frontend folder can be added later by Prajakta.

## Backend

```bash
cd backend
npm install
```

Create `.env` from `.env.example`, add your MongoDB URI, then:

```bash
npm run dev
```

Seed demo products:

```bash
npm run seed
```
